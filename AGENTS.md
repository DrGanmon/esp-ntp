# Projektvorgaben

- Nach jeder Änderung an diesem Projekt in der Abschlussantwort eine passende
  Commit-Message auf Deutsch als kopierbaren Textblock mitliefern.
- Die Commit-Message anhand aller Änderungen seit dem letzten Commit formulieren,
  einschließlich neuer, noch nicht versionierter Dateien. Keine bereits
  committeten Änderungen erneut aufführen.
- Nur die Commit-Message erstellen; einen Commit nur auf ausdrücklichen Wunsch
  ausführen.
